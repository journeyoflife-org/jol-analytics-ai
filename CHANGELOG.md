# Changelog

All notable changes to jol-analytics-ai will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [0.1.0] — Initial Release

### Added
- Project scaffolding with GDPR-compliant structure
- Security: JWT authentication, PII redaction, RBAC
- Anonymisation: k-anonymity validation, pseudonymisation
- ML: training, evaluation, inference, fairness testing, model registry
- RAG: embeddings, chunking, retrieval, vector access control, guardrails
- API: FastAPI application with health, inference, and RAG endpoints
- Airflow: data governance policies, DAG structure
- dbt: model/source/macro/exposure directories
- Compliance: GDPR, DPIA, audit, and risk documentation
- Scripts: PII audit, model card builder, lineage export, k-anonymity verifier
- CI/CD: GitHub Actions for CI, compliance checks, CodeQL, Qodana
- Testing: unit, integration, security, and fairness test suites
